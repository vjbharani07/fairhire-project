SkillMatch Transparency Manifesto

Our ethical commitment to structured, job-related hiring.

🚫 What SkillMatch NEVER Uses

We completely strip and ignore demographic, social, and non-job-related attributes:

✕ Gender ✕ Religion ✕ Caste ✕ Photographs ✕ Family Background ✕ Politics ✕ Personal Ties ✕ Zip Code Bias

✓ The 6 Verified Merit Pillars

1. Academic Performance: Documented persistence across 10th, 12th, and ongoing degree semesters.
2. Technical Skills: Hands-on proficiency verified via assessments and project demonstration.
3. Assessments: Standardized code comprehension and algorithmic logic tests.
4. Certifications: Recognized credentials from verified institutions (NPTEL, Coursera, Oracle).
5. Practical Projects: Real-world applications with inspectable public Git repositories.
6. Relevant Experience: Practical internships and documented hands-on industry apprenticeships.
Human Oversight: SkillMatch empowers recruiters with objective verification, but all final hiring offers remain with authorized human talent leaders.
